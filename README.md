# Uni Dear Data project
Create data visualisation of which perfume i wear most frequently. The project explores patterns in my perfume decisions.
I record each occasion i wear a perfume. The dataset contains the following information:

Perfume name- The name of the perfume worn

Company name- The name of the brand

Concentration- The amount of oil in the perfume

Date- The date the perfume was worn

Each row represents one occasion I wore a specific perfume.
The project is created using Processing. The sketch uses bubbles to represent individual perfumes. Each bubble represents one perfume, larger ones displaying a higher wear count, and smaller ones displaying a smaller wear count. The number of wears is displayed under each bubble.
